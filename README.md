# 宇佐合気道会 公式サイト

## 概要
宇佐合気道会の非公式ホームページです。

## 使用技術
- HTML / CSS
- Vue.js 3（CDN版）
- Google Calendar API（稽古日程表示）
- Open-Meteo API（宇佐市の天気表示）

## ファイル構成
- `index.html` — トップページ
- `past.html` — 過去の活動
- `faq.html` — よくある質問
- `calendar-vue.js` — カレンダー＆天気のVueアプリ
- `css-*.css` — スタイルシート

## 動作確認
ブラウザで `index.html` を直接開くか、ローカルサーバーで確認してください。

## 開発環境の起動方法
プロジェクトフォルダに移動して以下を実行：
```bash
npm run dev
```

## 画面表示
ブラウザで'http://localhost:5173'を開く。
